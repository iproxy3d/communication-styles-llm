Статья и локальная демонстрация динамического управления поведением LLM через скрытые микродиалоги.

## Основная идея

Эмоция отвечает на вопрос «что персонаж чувствует?», а коммуникационный стиль — «как он это выражает?». Перед текущей генерацией приложение выбирает короткий микродиалог и помещает его в контекст LLM как локальный образец поведения. Это позволяет менять манеру ответа на каждом шаге без переобучения модели и специальных emotional tokens.

Отдельный мотивационный микродиалог регулирует не тон, а степень вовлечённости агента: от стремления завершить контакт до инициативного продолжения разговора.

## Локальная демонстрация

Демо содержит три персонажа — поддерживающего, формального и ироничного. Один запрос можно прогнать без стиля и с каждым персонажем, увидев:

- полный 28-мерный вектор эмоций пользователя `U_t` от Multi-Motions 28;
- состояние агента `E_t`;
- смешанное состояние `S_t`;
- выбранное из 28 эмоциональных полей таблицы стиля;
- коммуникационный и мотивационный микродиалоги;
- точный контекст, переданный локальной LLM;
- итоговый ответ.

Инструкции запуска находятся в [`demo/README.md`](demo/README.md).

## Ограничения демонстрации

Классификацию эмоций в демо выполняет опубликованная EN/RU модель **Multi-Motions 28**: её 28 независимых sigmoid confidence scores формируют `U_t`. Для прозрачности учебного примера рекуррентное обновление состояния агента `E_t`, словарно-морфологическое извлечение сущностей для ассоциативной памяти и небольшая генеративная LLM реализованы компактно. Эти компоненты можно заменить независимо, не меняя механизм выбора и вставки микродиалога.

## Практика

Для практической реализации эмоционального входа `U_t` используется **Multi-Motions 28** — единый EN/RU классификатор на базе XLM-R, возвращающий полный вектор из 28 GoEmotions confidence scores. Он уже подключён к `demo/`: весь 28-мерный эмоциональный профиль передаётся в `U_t`, смешивается с состоянием агента `E_t` и памятью, после чего выбирается соответствующее эмоциональное поле коммуникационного стиля. База по умолчанию содержит микродиалоги для всех 28 эмоций у каждого из трёх персонажей и трёх уровней интенсивности. Поле `neutral` тоже заполнено: при нейтральном состоянии система сохраняет выбранную манеру персонажа, а не возвращается к усреднённому стилю LLM.
